# Context

Aquanova was developed at ProA La Falda during 2025 as an educational project addressing a need from fish farmers.

# My role

As a teacher, I supported the student team, led project decisions, and participated in technical validation. The students owned the development work.

# Solution

The device aims to measure water-quality parameters in real time, reduce reliance on manual measurements, and generate information to predict which chemicals should be added. The goal is to optimize costs and improve fish farming.

# Public scope

Project images are not published because they belong to the students. The portfolio presents the problem, the educational process, and my technical mentoring role.
