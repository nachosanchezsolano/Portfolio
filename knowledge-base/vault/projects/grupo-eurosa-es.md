# Contexto

Grupo Eurosa es una empresa de productos de aluminio con presencia en más de 13 países. El cliente tenía un sitio HTML estático y necesitaba actualizar productos, categorías y paseos virtuales con mayor autonomía.

# Mi rol

Trabajé como desarrollador independiente. Diseñé y desarrollé la nueva web, integré el frontend con un CMS en WordPress mediante GraphQL y adapté la solución al servidor existente en DonWeb.

# Solución

La plataforma utiliza Next.js y está desplegada en Vercel. WordPress funciona como CMS para que el cliente pueda administrar el contenido sin depender de un desarrollador. También desarrollé un endpoint central y un sistema de visualización para más de 100 dispositivos, con previsualización de cambios antes de publicarlos en producción.

# Resultados

El cliente puede administrar productos, categorías y paseos virtuales de forma independiente. También mejoraron el SEO, la estabilidad global y las visitas al sitio. No cuento con datos verificables de ventas o consultas, por lo que no hago esa afirmación. Actualmente mantengo el servidor y desarrollo nuevas actualizaciones según los requisitos del cliente.
