# ADR-001: Markdown as the canonical knowledge source

- Status: Accepted
- Date: 2026-08-21

## Decision

Professional knowledge will be stored as Markdown with YAML frontmatter. Obsidian is an editor and workflow, not a domain dependency.

## Consequences

The engine can support plain Markdown, Obsidian vaults, and Git-managed repositories. The content contract must be versioned and validated.
