# Contributing

Contributions should improve the reusable engine, not add personal portfolio content.

Before opening a change:

- Read the README and architecture documents.
- Use fictional or generic fixtures.
- Check whether the change belongs in an ADR.
- Add tests for new behavior.
- Confirm that no secrets or private information are included.

Good first contributions include parser tests, retrieval evaluation cases, Docker improvements, and new knowledge-source adapters behind existing ports.
